# flashconductor.github.io

A short address for [Conductor](https://github.com/Quidam2k/conductor), the free web app that cues a crowd to act together.

Nothing runs here. Each page only forwards to the app at https://quidam2k.github.io/conductor/:

- `/` opens the app (any `?query` or `#event` part is passed along).
- `/e/<name>` opens a named event. `/e/stillness` (and `/e/freeze`) open the built-in demo.
